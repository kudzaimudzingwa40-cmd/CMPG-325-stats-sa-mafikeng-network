# Initial GitHub Repository

Project name: **Stats SA Mafikeng Field Office (Mahikeng)**

## Purpose

This repository is the portfolio of evidence for the CMPG 325 network design project. It is organized so the lecturer can open the repository and immediately find the client requirements, design diagrams, IP plan, Packet Tracer work, configurations, tests, and troubleshooting notes.

The repository is intentionally structured from Milestone 1 onward. That makes it easier to build evidence gradually instead of trying to assemble everything at the end.
